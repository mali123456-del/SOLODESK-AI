# SOLODESK AI — Release Gaps Register (Phase Zero)

Prioritized gaps identified during the 2026-11-16 Phase Zero code & test audit, ranked against the 2026-12-05 release deadline.

| ID | Priority | Area | Concrete Gap Found | Target Resolution |
|---|---|---|---|---|
| GAP-01 | **P0 (Release Blocker)** | Database & Referential Integrity | `deleteProject` leaves orphan references; `updateInvoice` and `stopTimer` lack `db.transaction`; `recordPayment` uses `+ 0.0001` float comparison; `updateTask` / `createManualTimeEntry` miss foreign-key validation. | Harden `dexieRepositories.ts` transactions, `big.js` exact comparisons, FK checks, and safe project deletion guard/unlink. |
| GAP-02 | **P0 (Release Blocker)** | Backup & Restore Safety | Merge mode fails with Dexie `ConstraintError` if an incoming invoice has a different `id` but matching unique `&number`; conflicts omit non-core tables; PBKDF2 default is 100k; salt/IV decoded lengths not validated; no explicit pre-restore auto-recovery helper. | Upgrade `backupService.ts` merge reconciliation, full entity conflict inspection, 210k PBKDF2 (v1 backward-compatible), byte-length checks, and comprehensive failure tests. |
| GAP-03 | **P0 (Release Blocker)** | Schema Migration & Observability | No Dexie v3 schema for `workflowRuns` + knowledge deduplication/provenance fields; no database health/orphan/quota diagnostics service (`src/observability/`). | Add non-destructive Dexie v3 migration + `src/core/errors.ts` + `src/observability/healthCheck.ts` surfaced in Privacy & Storage settings. |
| GAP-04 | **P0 (Release Blocker)** | Business Logic Separation | `ClientsView.tsx` runs CSV client parsing/dedup directly in UI instead of a testable service. | Extract `importClientsFromCsv` into `src/services/importService.ts` with Zod validation & unit tests. |
| GAP-05 | **P0 (Release Blocker)** | Browser E2E Verification | Zero Playwright E2E specs exist; Playwright/Chromium not installed or attempted in workspace. | Build Playwright Chromium E2E test suite (`tests/e2e/`) and attempt execution against `vite preview` (or capture exact environment blocker + Windows verification command). |
| GAP-06 | **P1 (High Value)** | Security & CSP | No `src/security/` module; no strict tested Content Security Policy on `index.html`; crawler/URL importer protections unimplemented. | Add `src/security/urlPolicy.ts`, `src/security/sanitize.ts`, tested CSP meta policy, and docs (`SECURITY_REVIEW.md`, `PRIVACY_MODEL.md`, `THREAT_MODEL.md`). |
| GAP-07 | **P1 (High Value)** | AI Architecture & Tools | No provider-neutral capability registry (`src/ai/providers/registry.ts`); missing read-only tools (`explain_invoice`, `explain_project_profitability`, `suggest_expense_category`, `summarize_business_report`). | Implement capability registry and expand allowlisted analytical tools in `src/ai/agent/`. |
| GAP-08 | **P1 (High Value)** | Knowledge Hub & RAG Quality | No SHA-256 duplicate detection, collection filtering, or per-doc diversity ranking; evaluation suite only tests 2 cases without Recall@K / Precision@K / citation correctness. | Upgrade schema + `knowledgeService.ts` + `retrieval.ts` + expand benchmark to >= 6 curated test cases; document `DATASET_REGISTRY.md` & `DATASET_LICENSE_AUDIT.md`. |
| GAP-09 | **P1 (High Value)** | Approval-Gated Workflows | No workflow automation engine linking accepted proposals/quotations to draft projects/tasks/invoices with duplicate-execution guard & history. | Implement `src/workflows/workflowEngine.ts` backed by `workflowRuns` table and surface cleanly in Proposals / Quotations / Settings diagnostics. |
| GAP-10 | **P2 (Bounded Scope)** | Controlled URL Importer | No safe single-URL importer for Knowledge Hub. | Add `src/integrations/crawler/urlImporter.ts` with SSRF blocking, timeouts, byte cap, script stripping, CORS error explanation, and explicit user preview/approval. |
