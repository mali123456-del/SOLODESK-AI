- **Installed SDK:** `@google/genai` is installed at `2.32.0` (`>= 2.29.1`, supporting `gemini-4-hydrogen` per SDK guidance).
- **Environment Secrets Check (`env | cut -d= -f1`):** `GEMINI_API_KEY` is **NOT** currently present in the container environment, and there is no backend/API server in this static-first MVP.
- **Runtime Implications:**
  1. Core SOLODESK workflows must remain **100% functional offline without Gemini**.
  2. In Phase 9, AI features will be built behind an `AIProvider` interface (`GeminiProvider` + `MockProvider` for deterministic tests).
  3. Any browser-side BYOK key entered by the user must remain **in-memory only**, never persisted to IndexedDB/`localStorage`/backups/logs, with clear disclosure of DevTools/network visibility. If a server proxy is later added, `process.env.GEMINI_API_KEY` will be used server-side.
  4. Live Gemini API quota/rate-limit verification against Google servers remains **UNVERIFIED** without a user-provided key or server secret.

## 6. Preservation Decision

- **Preserve:** `.gitignore`, `tsconfig.json` strict settings (upgrading `include`/`jsx` rather than downgrading TS 7), `vite: ^8.3.8` baseline, `package.json` scripts (`dev` on port 3000, `build`, `lint`), `@google/genai`, and `public/assets/aistudio/...`.
- **Replace in Phase 1 (after approval):** `src/index.ts` and `src/index.css` starter XR cylinder boilerplate will be replaced with the React 19 + Tailwind CSS v4 SOLODESK shell.
- **Defer Removal Until Confirmed:** Heavy unused XR/3D dependencies (`xrblocks`, `three`, `@dimforge/rapier3d-simd-compat`, `@mediapipe/*`, `@pmndrs/uikit`, `@sparkjsdev/spark`, `troika-*`, `lit`, `openai`, `@types/three`, `@types/webxr`) are not imported by SOLODESK and should be removed cleanly once Phase 1 architecture is approved so bundle size and `npm install` times stay fast for low-spec hardware (i5-4200U / 8 GB RAM).
