# Proposal Writing & Scope Definition Guide

## Structure of a High-Converting Freelance Proposal
1. **Executive Summary / Overview**: Mirror the client's business goal in plain language before pitching technical implementation.
2. **Scope of Work & Inclusions**: Group deliverables into numbered milestones with clear handoff outputs.
3. **Explicit Exclusions & Assumptions**: Clarify dependencies (client copywriting, branding assets, hosting credentials, API accounts) and revision caps (e.g., two structured revision rounds per milestone).
4. **Timeline & Milestones**: Pair weekly checkpoints with realistic client feedback windows.
5. **Pricing & Payment Terms**: State total investment, currency, deposit schedule (e.g., 40% kickoff, 40% beta, 20% launch), and quotation validity window (typically 14–30 days).

## Change Request Rule
Any feature or deliverable added after acceptance requires a written change-order quotation or hourly billing rate approval before work starts. Never absorb unpriced scope changes silently.
