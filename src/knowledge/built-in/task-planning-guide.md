# Task Planning & Daily Execution Guide

## Prioritization Matrix for Solo Freelancers
- **Urgent**: Overdue client deliverables, broken production issues, or same-day invoice blockers.
- **High**: Core milestone tasks driving active project revenue this week.
- **Medium**: Planned sprint items, client review follow-ups, and scheduled QA checks.
- **Low**: Internal backlog cleanup, portfolio updates, and non-urgent research.

## Kanban & Subtask Hygiene
1. Keep `in_progress` WIP small (2–3 active tasks max) so context switching stays low.
2. Break multi-day deliverables into checkable subtasks taking 30–120 minutes each.
3. Attach due dates to client-facing tasks so overdue indicators surface risks in My Day and Notifications before deadlines slip.
4. Review tasks due today each morning alongside upcoming client appointments.
