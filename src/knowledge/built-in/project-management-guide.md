# Project Management & Delivery Control Guide

## Milestone-Driven Execution
Break every client project into 2–5 tangible milestones with target dates, acceptance checks, and a linked task backlog:
- **Planning**: Kickoff checklist, access verification, architecture or wireframe review.
- **Active**: Core execution tracked with weekly status updates and estimates-vs-actuals hour monitoring.
- **On Hold**: Document blocker reason and waiting-on-client owner clearly in project notes.
- **Completed**: Final deliverable handoff, documentation export, and closing invoice settlement.

## Protecting Project Budgets & Margins
- Compare logged billable hours multiplied by hourly rate against agreed fixed budget weekly.
- Trigger a mid-project scope review whenever actual hours reach 70% of estimated hours while progress is below 65%.
- Keep project notes updated with client decisions so scope disputes never rely on memory.
